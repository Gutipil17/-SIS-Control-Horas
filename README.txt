SIS CONTROL DE HORAS v2

1. Para prueba inmediata: abra index.html.
2. Para instalar como PWA offline en iPhone: publique esta carpeta en GitHub Pages/HTTPS, ábrala una vez en Safari y use Compartir > Añadir a pantalla de inicio.
3. Después de la primera carga, el Service Worker conserva la app para uso sin internet.
4. Los datos se guardan localmente. Use Reporte > Exportar respaldo periódicamente.

Base inicial: HK-3911, septiembre 2026. Total confirmado: 97,4 h.
